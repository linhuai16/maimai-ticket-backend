Provider 账期结算

用户支付款进入麦麦商户账户；本页根据 Provider 结算价生成应付账单。销售增加应付，整单退款按原 Provider 结算额冲减，特殊费用通过调整项体现。

账期边界：对账解决“订单/退款/票是否一致”，结算解决“本期最终应付 Provider 多少钱”。确认账单前可以重新生成和调整；确认后不可改写明细。

新建账期

同一 Provider 不允许创建日期范围重叠的账期。

结算口径

  • SALE：按订单项 `settlement_price / settlement_unit_price × quantity` 增加应付。
  • REFUND：整单退款成功时按原 Provider 结算额冲减；不是按用户退款金额直接冲减。
  • ADJUSTMENT：用于供应商特殊手续费、跨期差额、负余额结转等人工核准项。
  • 净应付 = 销售应付 - 退款冲减 + 调整项。
